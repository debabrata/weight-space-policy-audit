# Publication notes

An exploratory, code-assisted policy audit inspired by weight-space programming.

The article, source, learned weights, prompts, responses, scores, and recorded
pilot outcomes are published together. This is a limited pilot with one completed
assisted audit; the incomplete controls and output-format failure remain visible.

The publication copy replaces the author's absolute workspace path with
`<workspace>` and removes ephemeral Codex session identifiers from event logs.
These transformations do not change the network weights, responses, numerical
results, source code, or reported token usage. Original local records are retained
in the author's workspace. Historical command files document the recorded run;
use the README's fresh-copy instructions to run it on your machine.
